# Peach Byte Digital World

Premium official website for **Peach Byte Digital World** — a digital solutions company based in Fredericton, New Brunswick, Canada.

**Slogan:** *I turn ideas into working apps and softwares.*

## Features

- Clean, premium white + peach design language matching the official logo
- Fully responsive (mobile-first)
- WhatsApp-only contact system (`+1 226 480 7116`)
- Floating WhatsApp button
- Service sections: Websites, Custom Software, Business Tools, Automation & AI
- Digital products catalogue (demo-ready)
- Portfolio showcase
- SEO meta tags, accessible markup, fast static delivery

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repo in [Vercel](https://vercel.com).
3. Framework Preset: **Other** (or leave blank — static site).
4. Deploy. No build step required.

Alternatively, drag-and-drop the entire `peach-byte` folder into the Vercel dashboard.

## Local preview

Open `index.html` in a browser, or serve with any static server:

```bash
npx serve .
# or
python3 -m http.server 3000
```
